# Pearl & Vow

Статический сайт свадебного агентства по презентации «Компания Pearl & Vow 3(1).pdf». HTML, CSS и JavaScript без сборки и серверной части.

## Локальный просмотр

Откройте index.html в браузере или запустите из папки проекта:

```sh
python -m http.server 8080
```

Перейдите на http://localhost:8080. Локальный сервер нужен для надёжной проверки браузерных функций; копирование в буфер также работает на HTTPS в GitHub Pages.

## Контакты

В `config.js` заполните нужные значения:

```js
window.PEARL_CONFIG = Object.freeze({
  telegram: 'lizabacd',
  phone: '',       // Например: +7 ...
  email: '',
  whatsapp: '',    // Номер с кодом страны
});
```

Пустые телефон, почта и WhatsApp скрыты. Telegram уже подключён. Форма создаёт редактируемый текст обращения, который посетитель копирует и самостоятельно отправляет в Telegram. Форма не отправляет данные автоматически, не записывает их в localStorage и не использует сервер. Токены ботов, CRM и другие секреты нельзя помещать в публичные файлы сайта.

## Публикация на GitHub Pages

1. Создайте репозиторий и поместите содержимое этой папки в его корень: `index.html`, `styles.css`, `script.js`, `config.js`, `.nojekyll`, папку `assets`.
2. В GitHub откройте Settings → Pages.
3. В разделе Build and deployment выберите Deploy from a branch.
4. Выберите ветку main и папку / (root), нажмите Save.
5. После завершения публикации GitHub покажет адрес сайта.

Относительные пути `./assets/...` поддерживают публикацию по адресу `https://имя.github.io/название-репозитория/`. Сборка, npm и база данных не нужны. Регистр имён файлов важен: `.JPG` и `.jpg` различаются. Не переименовывайте изображения без обновления ссылок.

## Перед публикацией

- Уточните и добавьте оставшиеся контакты в config.js.
- Подтвердите права на публикацию фотографий. Сейчас изображения представлены как подборка вдохновения, а не как выполненные агентством проекты.
- При появлении реального портфолио обновите подписи и раздел «Вдохновение».
- При подключении стороннего сервиса заявок или аналитики отдельно настройте обработку данных и соответствующую информацию для посетителей.

Шрифты загружаются с Google Fonts; при отсутствии доступа используются Georgia и Arial. Аналитика, CRM и CMS из презентации не подключены: для них пока нет идентификаторов и настроек. На GitHub Pages сайт работает без них.
