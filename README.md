# Pearl & Vow

Статический многостраничный сайт на HTML, CSS и JavaScript без сборки и сервера заявок.

## Локальный просмотр

Откройте index.html либо запустите `python -m http.server 8080` из корня проекта и откройте http://localhost:8080.

## Страницы и стоимость

Главная — index.html; услуги — proposal.html, wedding.html, ceremony.html. Каталог услуг, варианты, цены и базовая плата редактируются в pricing.js. Расчёт — calculator.js. Источники и допущения цен — PRICING.md. Все позиции по умолчанию выключены; обязательной базовой платы нет. Выбор не сохраняется после перезагрузки. Ориентиры требуют согласования.

## Контакты и передача сообщения

В config.js указана временная почта alext.ya@ya.ru; telegram, whatsapp и phone пока пустые. Для Telegram укажите username без @, для WhatsApp — международный номер. После заполнения соответствующие контакты появятся рядом с почтой; форма начнёт открывать конкретного получателя.

Посетитель заполняет форму и нажимает «По почте», «В Telegram» или «В WhatsApp». Текст формируется автоматически из полей и текущего расчёта. Почта открывается через mailto с адресом, темой и текстом. Telegram с адресатом использует t.me/username?text=, без адресата — меню выбора чата через t.me/share/url. WhatsApp использует wa.me/номер?text=; при пустом номере — выбор получателя. При отсутствии адресата в интерфейсе есть явная подсказка. Сообщение отправляет посетитель в приложении; сайт не знает, было ли оно отправлено.

Можно сначала просмотреть и отредактировать текст. Ссылки обновляются при редактировании. Окно с текстом остаётся как запасной способ: если приложение не установлено, обработчик почты не настроен или длинный текст не перенёсся, его можно скопировать вручную. Поддержка перехода зависит от браузера и версии приложения. Автоматическое получение, хранение заявок, localStorage и секретные токены не используются.

Подготовка текста и ссылок — message-links.js, интерфейс — script.js. Использованы официальные форматы: https://core.telegram.org/api/links#public-username-links и https://core.telegram.org/api/links#share-links, https://faq.whatsapp.com/5913398998672934, https://www.rfc-editor.org/rfc/rfc6068.

## Публикация

Для GitHub Pages загрузите в корень репозитория все HTML-страницы, styles.css, config.js, script.js, pricing.js, calculator.js, message-links.js, .nojekyll и assets. В Settings → Pages выберите main и / (root). Относительные пути поддерживают публикацию в подпапке. Основная рабочая версия в корне; вложенная wedding_site синхронизирована для совместимости.

В assets/optimized находятся уменьшенные изображения, компактный логотип и favicon. Исходники сохранены. Фотографии обозначены как вдохновение; права на публикацию следует подтвердить. Google Fonts загружаются извне, запасные шрифты — Georgia и Arial. Подключена Яндекс.Метрика, счётчик 114304677. CRM не подключена.

### Telegram на ноутбуке

При выборе Telegram на компьютере используется прямая ссылка https://web.telegram.org/k/#?tgaddr= с вложенной командой tg://resolve или tg://msg_url. Промежуточная страница t.me не открывается. На мобильных устройствах выбирается ссылка установленного приложения. В окне доступны оба варианта явно: «Telegram в браузере» и «В приложении Telegram». После первого входа в веб-клиент может потребоваться повторно нажать кнопку с сайта, чтобы восстановить параметры черновика. Текст остаётся доступным для копирования.

Поддержка параметра tgaddr в исходниках Telegram Web K: https://github.com/morethanwords/tweb/blob/master/src/index.ts. Форматы команд: https://core.telegram.org/api/links.

### Яндекс.Метрика

На всех четырёх страницах установлен счётчик 114304677 с предоставленными настройками: Вебвизор, карта кликов, точный показатель отказов, отслеживание ссылок и ecommerce через dataLayer. События ecommerce сайт пока не формирует. Скрипт загружается асинхронно в head, noscript-пиксель расположен в body. После загрузки обновлённых HTML в GitHub и завершения публикации проверяйте полный адрес https://oooleksandrrrr.github.io/wedding_site/index.html в интерфейсе Метрики. Локальная установка кода не подтверждает появление посещений в отчётах.

## Подрядчики

Страница contractors.html доступна из меню всех страниц. Публичные контакты и описания редактируются в contractors-data.js; карточки формирует contractors.js. Сейчас добавлены три реальных примера по официальным источникам (ссылки есть в карточках), но сотрудничество не подтверждено. Для подтверждённого партнёра после согласования поставьте example: false; общая пометка о примерах скроется, когда примерных карточек не останется. Не добавляйте неподтверждённое партнёрство. Телефон, почта, Telegram и сайт необязательны; пустые контакты скрываются. Карточки без JavaScript показывают исходную подборку, поэтому при изменении списка обновите также статические карточки contractors.html. При публикации загрузите contractors.html, contractors-data.js, contractors.js, обновлённые script.js, styles.css и HTML других страниц. Метрика сохранена на новой странице.
